SAT PROBLEM-SOLVING & DATA ANALYSIS

Turn data questions into clear relationships before you calculate.

College Board’s current SAT framework includes ratios and rates, percentages, one- and two-variable data, probability, inference from samples and margin of error, and evaluation of statistical claims in Problem-Solving and Data Analysis. The common thread is quantitative reasoning: deciding what the numbers mean before manipulating them.

Core skills in this SAT Math domain

Ratios, rates, units, and proportional relationships

Find a useful unit rate, keep units visible, and scale only after the relationship is clear. Dimensional reasoning can expose an incorrect setup quickly.

Percentages

Identify the original or reference value before computing percent change. Distinguish percent increase from percentage-point change and translate percent language into a multiplier when useful.

One-variable data

Interpret distributions and measures of center and spread. Ask how an outlier or data change affects the mean, median, range, or other summary.

Two-variable data

Read scatterplots and models, interpret slope and predictions, and distinguish what the model estimates from what the observed data prove.

Probability

Define the sample space before dividing. Conditional probability changes the relevant group of possible outcomes.

Samples and statistical claims

Evaluate what a sample can support, how margin of error affects an estimate, and whether a study design supports association or a causal conclusion.

A reusable data-question process

  1. Identify the quantities and units. Write down what each number represents.
  2. Name the relationship. Is this a rate, percent change, average, probability, linear model, sample estimate, or study-design question?
  3. Define the denominator. Many percent and probability errors come from dividing by the wrong reference group.
  4. Calculate only what the question asks for. Avoid carrying extra arithmetic that creates new opportunities for mistakes.
  5. Interpret the number in context. Check the units and whether the conclusion is stronger than the data justify.
Common trap: treating correlation as causation. An observational relationship can be meaningful without proving that one variable caused the other.

Percent problems become simpler with multipliers

A 20% increase means the new value is 120% of the original, so multiplying by 1.20 can be more direct than finding the increase separately. A 20% decrease means 80% remains, so the multiplier is 0.80. For reverse-percent problems, identify which value is the original before solving.

Graphs and tables are part of the reasoning, not decoration

Before reading every number, identify the variables, axes, units, and comparison being asked about. For a line of best fit, distinguish between an observed data point and a model prediction. For tables, calculate only the rows or columns needed for the requested comparison.

SATprep.io approach: practice explanations focus on the reasoning process—such as choosing the correct denominator or distinguishing association from causation—so a student can apply the same process to a new dataset.

Build a data-analysis plan from skill-level evidence

A student may be comfortable with percentages but weak in conditional probability or statistical claims. Tracking those skills separately allows practice time to follow the actual evidence instead of repeating an entire broad Math category.
