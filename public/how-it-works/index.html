METHODOLOGY

Personalization should have a reason behind it.

SATprep.io is designed to decide what a student should study next from evidence rather than from a fixed calendar. The system separates measurement from teaching, combines multiple sources of skill evidence, and updates priorities as performance changes.

1. Start with the evidence already available

If a family has prior testing, SATprep.io can extract usable academic signals from supported score reports. Those results are treated as prior evidence—not as a permanent label and not as a replacement for current performance.

Different assessments use different score systems, so SATprep.io preserves the native score type instead of pretending that a percentile, scale score, and content-mastery percentage mean the same thing.

2. Measure before teaching

The initial diagnostic is assessment-only. During the diagnostic, SATprep.io saves each response but intentionally withholds correct/incorrect feedback and explanations. That prevents the early questions from teaching material that could distort the student's later diagnostic performance.

The diagnostic covers the major Reading and Writing and Math domains and can add targeted confirmation based on prior evidence.

3. Turn broad results into specific skill priorities

A broad Math or Reading and Writing score can be useful, but it may not identify the next lesson. SATprep.io organizes evidence by specific SAT Suite skills so the learning path can distinguish, for example, linear equations from data analysis or inference from punctuation.

Important: SATprep.io mastery estimates are learning signals used to organize preparation. They are not official SAT/PSAT scores and should not be presented as guaranteed score predictions.

4. Teach, practice, and explain

Learning sessions are different from the diagnostic. During practice, students receive immediate feedback, the correct answer, and an explanation of the reasoning or process. The goal is not simply to count right answers; it is to make the underlying method more reliable for the next problem.

See an illustrative Math and Reading & Writing practice explanation to understand how the learning-mode feedback is designed.

5. Update the model as new evidence arrives

Practice performance and completed learning work become new evidence. Stronger skills can move down the priority list while persistent weaknesses receive more attention. This creates a feedback loop rather than a one-time placement decision.

6. Use official practice for official-format experience

SATprep.io focuses on skill diagnosis, instruction, and targeted practice. Students should also use current official College Board resources such as Bluebook practice tests to experience the official interface, timing, and adaptive test format before test day.
