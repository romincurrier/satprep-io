## Campaign operating principle
Every campaign should map to a real user need in the test cycle. Do not manufacture urgency. Use dates to help a family answer one of four questions:
1. What should I work on before this test?
2. How should I use the time I have left?
3. What did my new score tell me?
4. What should I change before the next test?

The product message remains: SATprep.io uses prior testing, an assessment-only diagnostic, and ongoing performance to determine which skills should be reinforced next. Do not promise a score increase.

## Negative-keyword concepts for paid search review
Before activation, evaluate exclusions for intents SATprep.io should not pay to capture, such as:
- jobs / careers
- teacher salary
- official registration / register (unless a page clearly directs to College Board and campaign intent is educational)
- leaked questions / answer keys / cheating
- PDF download requests for copyrighted official tests
- unrelated “SAT” acronyms

Do not mechanically apply negatives without reviewing actual search terms because some terms can have mixed educational intent.

## Email lifecycle calendar after consent/provider approval
Event-driven beats date blasts:
- account created but onboarding incomplete
- onboarding completed but diagnostic not started
- diagnostic started but incomplete
- diagnostic completed but first learning session not completed
- weekly progress summary
- new uploaded score report successfully interpreted
- score-release educational note only for users who have opted into relevant communications
- approaching user-entered test date, not inferred sensitive data

Do not send marketing email to a child account where consent/legal design does not authorize it. Parent-facing lifecycle should be the default commercial communication route for under-13 household flows.

## Measurement expectations
Date-driven campaigns should be evaluated on downstream product activation, not clicks alone:
1. qualified landing visit
2. signup start
3. account creation
4. onboarding completion
5. diagnostic start
6. diagnostic completion
7. first recommended learning session
8. 7-day learning retention
9. paid conversion only after billing is approved

Do not use student test scores, uploaded records, age, school, or skill weaknesses as advertising-audience attributes.

## Reverification requirement
Before any campaign is activated, recheck College Board’s current dates/deadlines and score-release schedule. Date changes should update this document, landing-page seasonal modules, paid-search scheduling, and lifecycle calendar together.
